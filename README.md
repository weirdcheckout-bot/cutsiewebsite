# Math Bestie 💗

A responsive, pink-themed maths practice site covering:
- Multiplying and dividing integers
- Constructing algebraic expressions
- Factoring expressions
- Place value and rounding

## Features
Worked examples, randomly generated practice questions across easy/medium/hard levels, topic filters, answer checking with explanations, session progress statistics, and a 20-question mixed mock exam.

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Publish with GitHub Pages
1. Open **Settings** in this repository.
2. Choose **Pages** in the sidebar.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then click **Save**.
5. Wait for the Pages deployment. Your site should be available at `https://weirdcheckout-bot.github.io/cutsiewebsite/`.

Progress counters are session-only and reset when the page is refreshed. The site uses Google Fonts when internet access is available; system fonts remain as a fallback.
